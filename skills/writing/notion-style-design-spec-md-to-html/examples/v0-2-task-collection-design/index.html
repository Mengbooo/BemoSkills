2.1 操作区配置驱动

这类规格文档适合把关键落点写成“文件 + 代码片段”的说明，而不是只写口头描述。

TypeScript task-card/index.tsx 
const ACTIONS_BY_STATUS = {
  collecting: ["skip", "unable", "complete"],
  completed: ["recollect"],
  expired: [],
};

complete / recollect

标题、描述和确认按钮共用一套 ActionSheet 结构。

unable

需要额外增加原因输入和必填校验。

待 UI 设计师最终确认筛选栏与 ActionSheet 的视觉细节。

“新增”或“重点改动”这类信息适合使用 badge 标记：

  • unableRecruitmentTask 新增
  • recollectRecruitmentTask 新增

3. 实施顺序

  1. Mobile 端 优先启动
    • 筛选栏
    • 统一 ActionSheet
    • 完成记录列表
  2. Admin 端 改动量较小
    • checkbox 列
    • 批量删除
  3. 联调 收尾
    • 前后端接口对齐
    • 页面行为回归验证
