三、接手提示

待确认：如果文档里存在“待优化”“待确认”“已知限制”，不要埋在普通段落里，应该升级为警示块。

当原始 Markdown 描述的是启动链路、构建链路或排障流程时，可以改写为更易扫读的流程块：

pnpm run docker:up └─ scripts/docker-up.sh local ├─ 1. 读取 local 环境变量 ├─ 2. 构建后端 jar ├─ 3. 执行 docker compose up -d --build └─ 4. 通过 gateway 提供统一访问入口
curl -i http://127.0.0.1:8088/api/heartbeat/health

四、常见问题排查

Q1：为什么这类文档不适合直接套通用博客模板？

因为这类内容信息密度很高，读者通常带着任务来查命令、看状态、看证据和接手步骤。博客式排版会削弱目录、表格和流程结构。

Q2：什么时候应该用这套 skill？

当你手里已经有一份结构化 Markdown，希望把它交付成可离线打开、可长期保存、适合交接阅读的 HTML 时，就很适合。
