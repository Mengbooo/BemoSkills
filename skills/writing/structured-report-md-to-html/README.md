# structured-report-md-to-html

把结构化 Markdown 报告转成同一风格的单文件 HTML。

## 这个 skill 解决什么问题

当你已经写好一份 Markdown，但希望交付成：

- 更正式
- 更适合阅读和接手
- 有目录、有提示块、有 FAQ
- 可以直接本地打开和转发

就适合用这个 skill。

## 最快用法

直接这样说：

```text
按 structured-report-md-to-html 处理这个 Markdown：
1. 先读懂结构，不要机械渲染
2. 保留原始事实、表格、命令和证据
3. 转成同风格单文件 HTML
4. 要有左侧目录、总结 callout、风险提示块、流程块、FAQ 和移动端适配
```

## 推荐场景

- 项目周报 / 阶段报告
- Docker / 部署 / 运维手册
- 验证记录
- 交接文档
- FAQ / 排障文档

## 不推荐场景

- 官网页面
- 海报
- 营销长页
- 幻灯片型内容
